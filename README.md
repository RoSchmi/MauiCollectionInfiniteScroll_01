### MauiCollectionInfiniteScroll_01

Creates 100 rows of example data in TableEntity format (Azure.Data.Tables) and displays these data in a CollectionView.

Infinite loading (creating) of additional data when scrolling beyond threshold.

Using combination of horizontally scrolling ScrollView and vertically scrolling CollectionView inside the ScrollView
